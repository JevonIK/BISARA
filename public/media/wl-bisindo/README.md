# WL-BISINDO sample attribution

These videos are selected samples from the WL-BISINDO dataset by Grace
Oktaviani Kindy, Glenn Leonali, and Henry Lucky (BINUS University).

Dataset: <https://www.kaggle.com/datasets/glennleonali/wl-bisindo>

Paper: _Word-Level BISINDO: A Novel Video Indonesian Sign Language Dataset and
Baseline Methods_, Procedia Computer Science 269 (2025), 249–258.
DOI: <https://doi.org/10.1016/j.procs.2025.08.277>

License: Creative Commons Attribution-NonCommercial 4.0 International (CC
BY-NC 4.0). These files may only be used for non-commercial purposes with
appropriate attribution.
