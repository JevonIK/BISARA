# WL-BISINDO sample attribution

These videos are selected samples from the WL-BISINDO dataset by Grace
Oktaviani Kindy, Glenn Leonali, and Henry Lucky (BINUS University).

Dataset: <https://www.kaggle.com/datasets/glennleonali/wl-bisindo>

Paper: _Word-Level BISINDO: A Novel Video Indonesian Sign Language Dataset and
Baseline Methods_, Procedia Computer Science 269 (2025), 249–258.
DOI: <https://doi.org/10.1016/j.procs.2025.08.277>

## Included samples

The app includes sample 3 for every one of the dataset's 32 labels. Files use
the original dataset naming convention: labels 0–11 use signer 0, labels
12–25 use signer 1, and labels 26–31 use signer 2.

This is a demonstration subset: one video per label, 32 of the source
dataset's 1,600 videos. It is suitable for showing isolated examples in this
non-commercial prototype. It is not a training set, a representative
signer-independent evaluation set, or sufficient evidence for calibrating a
gesture pass threshold.

| Labels | Glosses                                                            |

The regional scope is BISINDO Banten. These samples must not be presented as a
universal representation of all regional BISINDO variations.
